📡

藍牙實時儀表板

即時監控區域內所有網關 (Gateway) 廣播遙測封包、MQTT 伺服器連線狀態、點滴與尿袋實時狀態牆與 JSON 即時訊息串流解析。

🏥

護理安裝與綁定 SOP

行動護理推車標準作業流程：護理人員驗證登入、掃描病人手環條碼、掃描 BT 傳輸器條碼，自動綁定病人並啟動 7 天動態倒數計時監測。

🔍

BLE 廣播與硬體掃描分析儀

獨立跨平台 BLE 廣播探針：即時解析 MEDFLO-* 傳輸器與 NMGW2601-* 網關 Manufacturer Data (0xFFFF)、GPIO18 狀態、電池低電量警示與 CSV Log 記錄分析。

🖥️

PC USB / 網絡工作站

MedFlow PC 桌面級物理層除錯與通訊整合中心：支援 USB Serial COM Port 115200/921600 bps 波特率診斷、網關狀態即時讀取與韌體燒錄控制。

🚀

OTA 發布與 MQTT 設備管理

網關韌體發布與全網在線管理中控台：支援區域網路 HTTP 伺服器、GitHub Releases 韌體發布、USB / MQTT 單機與全網廣播 OTA 更新，及 MQTT 設備狀態遠端監控。

🏥

全網 Gateway 健康度與重啟監控儀表板

全網 Gateway 多台動態監控中控：實時掌握佈署在各病房的 Gateway 在線/離線狀態、自動偵測重啟次數、連續開機時間 (Uptime)、Buffer 積壓率與全網告警流。
